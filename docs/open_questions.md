## C. 이 개발 환경에서 확인하지 못한 것

- Windows 동작 전체 (경로·프로세스 트리 종료·`BELOW_NORMAL`·PowerShell 스크립트·OneDrive 감지). 코드는 `os.name`/`sys.platform` 분기로 작성했으나 실행은 Linux뿐.
- Kokoro 실행: HuggingFace·GitHub 릴리스가 개발 환경에서 차단되어 가중치를 받지 못했다. `reports/source_audit.md` 참조.
- 두 기기 사이 오디오 클록 드리프트, 휴대폰 영상의 VFR 여부 (11장 "미확인" 그대로).
- Gemini CLI의 실제 호출, Kaggle 커널의 실제 실행(ACE-Step 설치·T4 호환·속도·한도), 사용자 PC 성능. 개발 환경과 CI 러너에서는 계정/키 없이 할 수 없다.
